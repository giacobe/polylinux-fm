## START: File Manipulation Lab

In this lab you will practice core Linux file manipulation skills. Each level gives you a small filesystem task, such as creating a file, making a directory, copying evidence, moving suspicious files, removing incorrect files, and organizing an incident response workspace.

Throughout the lab:

- Read the level README carefully.
- Use the terminal on the right to inspect the files and complete the task.
- Run `validate` when you think the level is complete to print your key.
- Use the Quick Reference if you need a reminder for common commands.

**Let's get started!**

## LOGIN: Get On the Machine

Wait for the VM on the right to finish booting. Once the login prompt appears, log in.

At the login prompt, type:

```text
root
```

No password is required. Just press **Enter**.

If the lab has not been installed yet, change into the File Manipulation Lab folder and run:

```bash
sh installfmlab.sh
```

Enter your email address when prompted. The lab uses it to generate personalized level targets.

## REF: Quick Reference

| Task | Command |
| --- | --- |
| Show where you are | `pwd` |
| List files and directories | `ls` |
| List details, including permissions and owner | `ls -l` |
| List hidden files too | `ls -la` |
| Change into a directory | `cd [ directory ]` |
| Move back up one directory | `cd ..` |
| Display a text file | `cat [ filename ]` |
| Create an empty file | `touch [ filename ]` |
| Create a directory | `mkdir [ directory ]` |
| Create nested directories | `mkdir -p [ path ]` |
| Copy a file | `cp [ source ] [ destination ]` |
| Move or rename a file/directory | `mv [ source ] [ destination ]` |
| Remove a file | `rm [ filename ]` |
| Remove an empty directory | `rmdir [ directory ]` |
| Print your current key | `validate` |
| Change to the next level | `nextlevel` |
| Change to the previous level | `prevlevel` |

## INST: Instructions: Working Through a Level

Each level starts with a `README.txt` file. Read it first:

```bash
cat README.txt
```

Then inspect the files and directories around you:

```bash
pwd
ls
ls -l
```

After completing the objective, run:

```bash
validate
```

After recording your key, move on when you are ready:

```bash
nextlevel
```

## INST: Instructions: Validation

The `validate` command prints a key for the final filesystem state of your current level. It does not show a correct or incorrect status. The key is generated by hashing a cleaned file listing, including names, sizes, permissions, owner, and group, while ignoring date and time fields. If your instructor uses a form, submit the key shown by `validate`.
